# CertDocket Marketing Website

Marketing site for CertDocket — automated compliance certificate management.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Vercel (deployment)

## Development
npm install && npm run dev

## Deployment
Deployed via Vercel. Push to main triggers production deploy.
